# Matriz · momento do parto

Tabela única de referência para todos os cenários abordados.

## Pré-eclâmpsia

| Cenário | Conduta | Idade do parto |
| --- | --- | --- |
| PE sem gravidade | Vigilância + anti-hipertensivo de manutenção | Até termo (40 sem) |
| PE com gravidade <34 sem · estável | Internar, sulfato, anti-hipertensivo, corticoide; conservar se possível | Após estabilização e maturidade fetal |
| PE com gravidade ≥34 sem | Estabilizar e parto | Imediato após estabilização |
| Eclâmpsia | Sulfato, anti-hipertensivo, parto | Imediato após estabilização |
| HELLP <34 sem · estável | Corticoide + considerar conduta conservadora curta | Estabilizar e parto em ~24–48h |
| HELLP ≥34 sem ou instável | Estabilizar e parto | Imediato |
| Iminência de eclâmpsia | Sulfato + estabilizar + parto | Imediato após estabilização |

**Via:** vaginal possível após estabilização. Cesárea por critério obstétrico, não automática pela PE.

## Diabetes

| Cenário | Idade do parto |
| --- | --- |
| DMG sem medicação · bom controle | Até 40 semanas |
| DMG com medicação · bom controle | 39 semanas |
| Diabetes prévio com bom controle | 39 semanas |
| Diabetes mal controlado | 37–38 semanas |
| Macrossomia ou polidrâmnio | Considerar 37–38 sem |
| Sofrimento fetal ou complicação materna | Imediato (avaliar maturidade) |

**Via:** vaginal possível. Cesárea por critério obstétrico (macrossomia >4.500 g, distócia anterior, sofrimento fetal).

## Gemelaridade

| Corionicidade / amnionicidade | Idade do parto |
| --- | --- |
| Dicoriônica diamniótica | Até 38 semanas |
| Monocoriônica diamniótica | Até 36 semanas |
| Monoamniótica | 32–34 semanas (cesárea) |
| Gêmeos conjugados | Cesárea (idade conforme caso) |
| ≥3 fetos | Cesárea |

**Via vaginal possível**: dois fetos, cavidades amnióticas separadas, primeiro feto cefálico, sem complicação grave.

**Cesárea obrigatória**: monoamniótica, conjugados, ≥3 fetos, 1º não cefálico, TFF grave, gemelar complicado.

## Hiperêmese

Não muda o momento do parto — é doença do 1º trimestre, geralmente resolvida antes de 20 semanas. Casos refratários graves podem indicar interrupção precoce em situações excepcionais (raro, conferir referência).
